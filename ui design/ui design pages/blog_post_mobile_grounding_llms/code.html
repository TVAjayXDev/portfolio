§ 01

The Hallucination Tax in Enterprise RAG

Standard vector search systems in Retrieval-Augmented Generation (RAG) suffer from a fundamental dissonance: vector similarity measures semantic proximity, not factual alignment. When passing top-k chunks to an LLM context window, intermediate summarization drops exact bibliographic coordinates.

In high-stakes verticals—securities filings, healthcare protocols, and statutory compliance—an unsupported synthetic phrase is worse than a hard query failure. We engineered TrustLens to bind generated tokens to exact, verifiable cryptographic signatures at the character-offset level.

§ 02

Deterministic Byte-Range Indexing

Instead of treating token sequences as raw strings, TrustLens assigns a unique Merkle leaf to every extracted paragraph segment. As the decoder streams its output, our runtime intercepts citation markers like [ref:8a4f] and performs an sub-millisecond local hash validation.

§ 03

TrustLens Locus Verifier

The core citation validator written in memory-safe Rust, compiled to WASM for browser-side mobile verification.

locus_engine.rs 
// In-memory verification of byte range bounds
pub fn verify_citation_span(
    manifest: &DocumentManifest,
    claim_hash: Blake3Hash,
    target_offset: ByteRange,
) -> Result<VerifiedLocus, AuditFault> {
    let node = manifest.tree.lookup_leaf(claim_hash)
        .ok_or(AuditFault::OrphanReference)?;

    // Byte-range boundary assertion
    if !node.span.encloses(&target_offset) {
        return Err(AuditFault::BoundaryDrift {
            expected: node.span,
            observed: target_offset,
        });
    }

    Ok(VerifiedLocus {
        source_id: manifest.doc_id,
        page_index: node.page,
        confidence: 1.0,
    })
}
